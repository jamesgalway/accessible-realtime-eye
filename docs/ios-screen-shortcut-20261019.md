# 苹果快捷指令呼出屏幕共享

用户已暂缓双画面，只授权从其他视频应用通过快捷指令呼出谷歌屏幕共享。新会话默认原“共享直连”；Google共享已经准备或正在运行时保留当前直连/绿云路线及会话，不另起Live。

原生AppIntent名称“开始屏幕共享”，App Shortcut短名称“屏幕共享”。可尝试用Siri说“用实时慧眼共享屏幕”或“打开实时慧眼屏幕共享”；也可在快捷指令的App快捷指令中选实时慧眼的屏幕共享动作，组合自己的触发方式。系统索引及Siri识别仍以手机实际结果为准，不把编译当真机验收。

备用公共URL入口为huiyan-screen://start，不带密钥、权限参数或模型选择。自建快捷指令可使用“URL”加“打开URL”动作；这两种触发进入同一个原生请求队列。只接受固定scheme/host/路径且无账号、端口、查询或片段的URL，其他链接不执行。

冷启动、已打开App、Siri退场时的请求都保存在主线程路由中，等App处于active再消费并进入原屏幕页面。沿原自动准备和一次性苹果广播面板流程；用户仍需在系统面板确认“开始广播”，之后返回原视频应用。取消过广播面板但仍已准备时，再次呼出只重开面板；共享已经启动则不重连、不清对话、不重复开广播。准备失败后再次呼出会重新创建页面并复用原准备入口。

仅增加系统入口及原页面路由，不修改模型、Key、音频、提示、搜索、任务合同或广播扩展，不实施后台双摄像头/屏幕功能。不自动控制原视频App播放，也不承诺绕过苹果广播确认或自动跳回任意第三方App。

按用户此前要求，不运行额外模型、模拟器或回归矩阵；新Swift代码正常编译及AppIntents元数据提取是打包所需步骤。安装和首次系统入口使用结果另在主项目实际发布记录中补充。

共享页左上方新增原生“返回慧眼主界面”，在旁白顺序中位于版本按钮之前。按钮只收起共享页面，原控制器继续持有当前广播、连接、声音及任务。主界面再点同一共享入口会展开原会话。原结束按钮在相机模式叫“结束慧眼”，共享模式叫“结束共享”，动作仍只结束当前所属功能；共享页不再重复放一份结束按钮。改选相机入口、版本或教学/导航仍沿原释放流程。没有自动退后台或跳回第三方应用，也没有修改提醒、持续播报和搜索规则。
