# 实时慧眼 iPhone 原生版

## 当前范围

这是独立于现有网页生产环境的 iPhone 原生工程。当前第一阶段只验证：

- 后置摄像头；
- 闪光灯人工开关，默认关闭，不允许模型自动控制；
- 支持机型上的 ARKit LiDAR 深度；
- 到绿云 Gemini 服务的 HTTPS 连接；
- 为主动提醒、找东西、持续播报和后续导航现场辅助预留互斥任务状态。

当前没有修改阿里和绿云线上代码，也没有修改导航规则。

## 架构边界

- 绿云仍负责 Gemini Live、合同签发、图片快筛和语音链路。
- 原生客户端负责摄像头、麦克风、闪光灯、LiDAR 和任务界面。
- LiDAR 只提供距离素材或拦截明显错误的伸手时机，不改目标、不改任务类别、不补合同。
- 导航以后只向现场辅助提供当前路段、下一步动作、终点道路和待确认目标；原生视觉层不得重新规划路线。

## 在 Mac 上生成工程

需要 macOS、Xcode 和 XcodeGen。进入本目录后运行：

```sh
xcodegen generate
open AccessibleVision.xcodeproj
```

在 Xcode 的 Signing & Capabilities 中选择自己的 Personal Team，再用数据线连接 iPhone 运行。免费 Apple ID 的设备签名通常七天后失效，需要重新运行安装。

## 第一轮真机验证

1. 启动后允许摄像头权限。
2. 确认旁白能读到“绿云服务连接正常”。
3. 点“打开闪光灯”，确认灯亮；再点一次确认关闭。
4. 面向桌面或墙面，点“读出正前方距离”，与实际距离做三组粗略比较。
5. 使用不带 LiDAR 的设备时，应用必须明确提示不支持，而不是伪造距离。

三个现场样例将在硬件底座通过后接入：桌面充电宝、倒水快满提醒、房间持续播报。
